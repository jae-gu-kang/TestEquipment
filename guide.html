상태 다섯 가지

원은 한 자리에 그대로 있고 모양과 글자만 바뀝니다. 오른쪽 아래 작은 원은 진행 중에는 중지, 끝난 뒤에는 다시 시작입니다.

사용 순서
  1. 연결

    맨 위 연결을 누릅니다. 장비 없이 연습할 때는 전송수단을 시뮬레이터로 둡니다. 실제 서보는 통신 설정을 펼쳐 CANable · 비트레이트 · 서보 ID 를 맞춥니다(Chrome 또는 Edge).

  2. 자동 시험

    자동 시험 화면 가운데 원을 누릅니다. 사전 점검(기준 · 서보 응답 · 운전모드 · 위치 한계) 뒤 통신 · 구형파 · 계단파 · 최대 각속도 · 주파수 응답 · 온도를 순서대로 수행합니다.

  3. 진행 확인 · 중지

    다른 탭을 보고 있어도 제목줄 칩에 진행률과 남은 시간이 나옵니다. 멈출 때는 원 옆 작은 원(■)을, 위험할 때는 제목줄의 빨간 비상정지를 누릅니다.

  4. 성적서

    끝나면 원에 PASS 또는 FAIL 이 뜹니다. 원을 눌러 성적서를 보고, 시리얼 번호 · 작업자를 적은 뒤 JSON 저장 · CSV 저장 · 인쇄 / PDF 중 하나로 남깁니다.

  5. 기준 바꾸기

    기준 설정 탭과 각 시험 탭의 시험 조건 · 판정 기준을 펼쳐 바꿉니다. 바꾼 기준은 이 브라우저에 저장되고, 성적서에는 시험 당시 기준이 함께 기록됩니다.
